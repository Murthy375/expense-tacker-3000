
# Expense Tracker 3000

A tracker to track where you spend and waste your hard earned money.


## Tech Stack

**Server:** 
- Node
- Express
- pnpm
- Redis
- PostgreSQL


## Prerequisites

- Node.js >= 18
- pnpm >= 9 (`npm install -g pnpm`)
## Installation

Install my-project with npm

```bash
  npm install my-project
  cd my-project
```
    
## Usage/Examples

```javascript
import Component from 'my-project'

function App() {
  return <Component />
}
```
